A web-based application designed to manage users and assign, track, and update tasks efficiently. This system is ideal for small teams, organizations, or project managers looking to streamline work allocation and monitor progress.

Project Description
The Task and User Management System allows administrators to:
Create and manage users (admin and regular users)
Assign tasks to users
Track task status (pending, in progress, completed)
View and manage task history

The system ensures accountability, transparency, and team productivity through structured task handling.

Features
Admin registration and role-based access (Admin/User)
Task creation, editing, and deletion
Status tracking (Ongoing, In Progress, Completed)
Dashboard view for Admin
Search and filter tasks

Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Django
Database: MySQL
Authentication: Django Auth
